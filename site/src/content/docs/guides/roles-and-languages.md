## Roles

A person can have several roles in an event: **attendee**, **speaker**, **organizer**, **volunteer**. Each role is its own certificate, so a speaker who also organized gets two. The workload can be set per role.

## Languages

A certificate is written in a language: the texts come from the plugin's translations and the event's own words. You choose in **Settings › Issuing › Languages** which languages are offered (none chosen means every installed language). A certificate page can be opened in each of them, for example `/certificado/CODE/en-us/`.

The names of the languages and the way dates are written follow the language of the certificate.
