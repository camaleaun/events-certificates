# Brand

Internal notes (not a page of the site). `npm run brand` in `site/` draws everything from `brand/logo.svg` and the wordmark:
`public/favicon.svg`, `public/apple-touch-icon.png`, `public/og-image.png` and the WordPress.org assets in `../.wordpress-org/`
(`icon-128x128.png`, `icon-256x256.png`, `banner-772x250.png`, `banner-1544x500.png`).

- **Mark:** a certificate with a gold seal and ribbon on the WordPress admin blue.
- **Colors:** blue `#3858e9` (white on it is 5.9:1), gold `#f0b849`, text `#1e1e1e`.
- **Type:** Inter Bold for the wordmark, turned into paths by the script so no font is needed to draw it.
